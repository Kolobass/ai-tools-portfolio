# Image Preparation

Підготовка зображень для публікації.

У проєктах із великою кількістю ілюстрацій повторювалася одна й та сама робота — підготувати файл для вебсторінки й текстовий опис для зображення.

Я працював над підготовкою alt-текстів і стисненням зображень. Ці завдання доповнювали редакційну перевірку матеріалу перед випуском.

## English overview

I worked on alt-text preparation and image compression for web publishing. These steps helped prepare assets for editorial review alongside the text and tables they accompanied.
