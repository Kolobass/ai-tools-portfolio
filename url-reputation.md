# URL Reputation Checks

Перевірка репутації адрес.

Іноді адресу позначає сервіс репутації, і команді потрібно з’ясувати, який саме статус він показує. Я працював з автоматизованими перевірками через VirusTotal.

Такі перевірки допомагали знаходити позначені адреси для окремого розгляду та повторної перевірки. Остаточне рішення про причину позначення залишалося за людиною.

## English overview

I used VirusTotal-based URL checks to identify addresses flagged by reputation services. The results supported manual review and follow-up checks when a classification appeared incorrect.
