# Search Results Monitoring

Моніторинг пошукової видачі.

Для SEO-аналізу потрібно знати, яку сторінку пошуковик показує за певним запитом. Я автоматизував збирання результатів через SE Ranking і пошукові API.

Результати використовували для перевірки позицій і зіставлення видимості сторінок із даними пошукового трафіку.

## English overview

I automated collection of search results through SE Ranking and search APIs. The resulting reports helped check which pages ranked for specific queries and compare visibility with search traffic.
